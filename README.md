# DWG 坐标导出工具

在 Windows 上预览 DWG 图纸，点选线或点，实时查看并导出 XYZ 坐标、长度与测量方位角到 Excel。

纯本地解析，不依赖 AutoCAD、中望、浩辰或 ODA 转换器，不写注册表、不需要管理员权限。

## 功能

- 打开 DWG（R14–R2018）并在窗口内预览，滚轮缩放、中键/右键拖拽平移、`F` 适配全图
- 工具栏「清空图纸」（`Ctrl+W`）卸下当前图纸：释放实体、空间索引、折线与画笔缓存并复位视图，便于连续读取多张图纸（不动磁盘文件）
- 点选直线、轻量多段线、二维/三维多段线、圆弧、圆、点；`Ctrl`/`Shift` 加选，左→右框选（窗口）、右→左框选（交叉）
- 工具栏「多选」（`M`）开启后连续单击即可追加多条线，一次导出多条线到同一张 sheet，块与块之间空一行
- 选中多段线后，画布用序号（1、2、3…）与沿线箭头标出点的先后顺序；工具栏「反向」（`R`）可把输出方向倒过来，已反向的线用粉色高亮区分，再按一次恢复（`Ctrl+Z` 同样可撤销）
- 工具栏「反算坡度」（`S`）可随时开关，默认关闭；打开后导出时自动填写坡度行，关闭时留空由你填写
- 选中即在右侧显示：起点/终点 XYZ、平面长度、三维长度、首段方位角（度分秒）、分段方位角与段长
- 待导出列表实时收集，可删除、定位、清空；`Ctrl+Z` 撤销、`Ctrl+Y` 重做，最多 200 步
- 一键导出「采场矿房坐标计算表」形式的 `.xlsx`：每个点两列合并，平距/巷道长/方位嵌在相邻两点之间，X/Y/Z 逐点排列；巷道长留空待填，坡度可选自动反算（默认关闭）
- 取点规则可切换：仅顶点 / 按间距采样（默认 1.0 图纸单位）
- 比例尺可选 1:100 / 1:200 / 1:500 / 1:1000 / 1:2000 / 1:5000（默认 1:1000），只用于把图上长度换算成平距
- 图层显示开关、实体类型过滤、中文路径、拖拽文件打开

## 环境与启动

需要 Python 3.10+（本机为 3.12）。

```bat
pip install -r requirements.txt
python app.py
```

或直接双击 `run.bat`（缺依赖时会自动安装）。

依赖：`ezdwg`（Rust 核心的 DWG 只读解析）、`PySide6-Essentials`（Qt 6 界面）、`openpyxl`（Excel）。

国内网络安装缓慢时可加镜像：

```bat
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 坐标与精度口径

| 项目 | 约定 |
|---|---|
| 坐标顺序 | 按图纸 CAD 坐标原样输出：X 为东向、Y 为北向，不交换 |
| 方位角 | 测量方位角：正北（+Y）起顺时针，0–360°，导出为度分秒（秒取整数） |
| 比例尺 | 默认 1:1000，即图上 1 个单位 = 实际 1 m；1:500 则 1 个单位 = 0.5 m。**只参与平距换算**，坐标仍按图纸原值输出 |
| 平距口径 | 沿路径的平面长度，圆弧段取弧长；直线取两点水平距离 |
| 坐标小数位 | 4 位 |
| 长度小数位 | 3 位 |
| 数值类型 | 全链路 IEEE-754 双精度（Python float / float64），不使用 float32 或 32 位整数 |
| 渲染精度 | 载入时以图形范围中心为原点平移，画布内只处理相对坐标，避免大坐标在光栅化时抖动 |
| Excel 精度 | 坐标按 4 位小数、平距按 3 位小数写入数值单元格；超大坐标仍受 Excel 15 位有效数字限制，导出信息表会记录口径 |

说明：图纸的 `$INSUNITS` 标记经常不可靠（例如实际以米绘制的矿山图标记为毫米），因此坐标默认按「图纸单位」原值导出，不做换算；确有需要可在导出对话框中选择「米 / 毫米」，按 `$INSUNITS` 换算。

平距不受 `$INSUNITS` 影响，只按所选比例尺换算：`平距(m) = 图上长度 × 分母 / 1000`。1:1000 的图，图上量到 2.215 就是 2.215 m；1:500 的图同一条线是 1.108 m。

## 操作

| 操作 | 方式 |
|---|---|
| 打开 | `Ctrl+O`，或把 `.dwg` 拖进窗口 |
| 清空图纸 | 工具栏「清空图纸」（`Ctrl+W`），只清内存与视图，不修改 DWG |
| 缩放 | 滚轮（以光标为锚点）、`Ctrl+=` / `Ctrl+-` |
| 平移 | 中键拖拽、右键拖拽、空格+左键拖拽 |
| 适配全图 | `F` |
| 选择 | 左键单击；`Ctrl`/`Shift` 加选；拖框批量选择 |
| 多选模式 | 工具栏「多选」（`M`）开启后，连续单击即可追加/取消选中，不必按 `Ctrl` |
| 反向点序 | 选中线后按「反向」（`R`）：点号、坐标、方位角与平距按新方向重算，已反向显示粉色高亮 |
| 反算坡度 | 工具栏「反算坡度」（`S`）开关，默认关闭；开启后导出时自动填写坡度行 |
| 删除选中 | `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 比例尺 | 工具栏或导出对话框下拉选择，默认 1:1000，影响平距换算 |
| 导出 | `Ctrl+E` 或工具栏「导出 Excel」 |
| 定位 | 双击待导出列表中的行 |

## 导出的表格形式

主表「坐标计算表」按采场矿房坐标计算表的阶梯式排版，每条选中线一个块：

```
工程名称 | 线1（可改为巷道名）            （横向合并）
点号     | P1    | P2    | P3    | ...   （每点两列合并）
平距(m)  |   2.215 |   6.041 | ...        （嵌在相邻两点之间）
巷道长(m)|       （留空，由使用者填写）
方位     | 211°47′10″ | 244°21′46″ | ...  （度分秒，秒取整数）
坐标(m)  | X | 各点 X 坐标（每点两列合并）
          | Y | 各点 Y 坐标
          | Z | 各点 Z 坐标
坡度     |  -1.00%  |   +0.50% | ...        （默认留空；打开「反算坡度」后 0.00% 填入）
```

- 一次可以选中任意多条线：**全部写在同一张 sheet 里**，每条线一块（9 行），块与块之间空一行；块的标题依次是 `线1/线2/…`，与「待导出列表」的顺序一致。
- 方向：画布上的序号与箭头是导出顺序；按「反向」（`R`）后点号改为 `Pn…P1`，坐标列、平距与方位随之倒序重算（方位角 = 原方位 + 180°，平距顺序反转，坡度符号跟着上下坡翻转），导出的表与列表、属性面板保持一致。
- 点号默认 `P1…Pn`，工程名称默认 `线1/线2…`，均可直接在表内改写。
- 平距 = 相邻两点的平面长度差 × 比例尺系数（圆弧段取弧长），保留 3 位小数；坐标保留 4 位小数；方位为测量方位角，度分秒整数秒。
- 巷道长不预填，保留数值格式供手工录入；同一块内可继续套用公式。
- 坡度默认留空；在主界面工具栏打开「反算坡度」开关后，按相邻两点**高差 ÷ 水平距离**（图纸原值）自动填入，格式 `0.00%`，上坡为正、下坡为负，与现场计算表的口径一致。开关在每次启动时默认关闭，本次运行内保持；导出对话框只显示当前状态，不再提供重复开关。
- 可勾选附加「导出信息」工作表，记录图纸路径、DWG 版本、坐标与方位角口径、取点规则等。

## 支持范围与限制

- 支持：LINE、LWPOLYLINE、POLYLINE_2D、POLYLINE_3D、ARC、CIRCLE、POINT
- 块参照（INSERT）会递归展开并应用插入点、缩放、旋转，块内图元可直接选中
- 文字、填充（HATCH）、标注、椭圆、样条暂不参与显示，也不可选；冻结/关闭图层默认不显示
- 图纸空间仅在模型空间为空时作为回退
- 仅读取，不修改原图

## 性能参考（本机）

- 12 MB、约 9.6k 实体的穿爆计划图：解析约 3.8 s，全图绘制约 20 ms，放大后约 12 ms
- 16 MB、约 5.5 万实体的现场执行图：解析约 7.7 s，全图绘制约 27 ms，放大后约 11 ms
- 9.9 MB、22611 实体的矿山总图：解析约 3.4 s（只枚举需要的实体类型），绘制缓存 0.22 s 在加载线程内完成
- 454 KB 剖面图：解析约 0.5 s

框选 6000+ 条要素时，待导出列表只计算当前可见行的总长，列表刷新约 3 ms。

### 1.3.1 性能优化（同机实测，min-of-N）

| 指标 | 优化前 | 优化后 | 做法 |
|---|---|---|---|
| 导出 100 条线 | 2369 ms | 115 ms | 单元格样式改成样式数组批量套用；合并绕开 openpyxl 逐格重算边框 |
| 导出 20 条线 | 318 ms | 30 ms | 同上 |
| 导出 1 条线 | 32 ms | 22 ms | 余下是建工作簿与落盘本身的开销 |
| 选中 10 万点长线后重绘 | 417 ms | 13 ms | 高亮改用底图那套抽稀折线；顶点方块按视口裁剪并限量抽样 |
| 选中 2 万点长线后重绘 | 84 ms | 21 ms | 同上 |
| 框选 5000 条后重绘 | 31 ms | 25 ms | 完整折线缓存从「超限整表清空」改为 LRU + 总点数预算 |

解析时间仍由 ezdwg 的实体枚举主导（9.9 MB 总图 3.6 s 里约 2.3 s 在枚举），
本程序侧没有可再压缩的空间；加载已有独立线程 + 进度提示，不阻塞界面。

## 打包为 exe

目标机器无需安装 Python，提供两种产物：

| 形式 | 位置 | 体积 | 说明 |
|---|---|---|---|
| 单文件版 | `dist\DWGCoordExporter.exe` | 约 46 MB | 一个 exe 直接拷走；启动时先解压到临时目录，首次打开比目录版慢几秒 |
| 目录版 | `dist\DWGCoordExporter\DWGCoordExporter.exe` | 约 111 MB | 启动快，文件多但便于排查缺库问题，整个文件夹一起拷贝 |

两者的崩溃信息都写入 exe 同级的 `logs\crash.log`。

重新打包：

```bat
build.bat            :: 目录版
build_onefile.bat    :: 单文件版
```

脚本会在 `.venv` 中安装 PyInstaller 并执行打包（已排除 matplotlib、scipy、pandas、numpy 等未使用依赖以控制体积）。
